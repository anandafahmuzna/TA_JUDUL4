# Daftar Kontak – PHP Sederhana
Project ini adalah aplikasi daftar kontak sederhana yang dibuat dengan PHP Native dan menyimpan data dalam file JSON.
Di dalamnya sudah ada fitur login, tambah data, edit, hapus, dan logout.

# Fitur yang Tersedia

- Login (username & password default)
- Logout
- Menampilkan daftar kontak
- Tambah kontak baru
- Edit kontak
- Hapus kontak
- Penyimpanan menggunakan file data.json (tanpa database)

# Penjelasan Singkat File

login.php → halaman untuk masuk, cek username & password

session_start.php → memastikan user sudah login sebelum membuka halaman lain

index.php → halaman utama daftar kontak

tambah.php → form tambah kontak

edit.php → form edit kontak

hapus.php → menghapus data kontak

data.json → tempat semua data kontak disimpan

# Catatan

Project ini tidak memakai database, jadi semua data disimpan di file JSON.

Cocok untuk tugas kuliah atau latihan PHP dasar.
